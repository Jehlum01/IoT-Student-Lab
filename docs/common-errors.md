# Common Errors

## Hardware

- Reversed LED polarity
- Missing LED resistor
- Loose breadboard connection
- Incorrect VCC/GND
- Incorrect GPIO
- Incompatible voltage
- Insufficient power

## Software

- Wrong board selected
- Wrong serial port
- Missing library
- Incorrect pin definition
- Syntax error
- Incorrect logic level
- Incorrect sensor assumptions

## Debugging Principle

Break the system into smaller pieces and verify each part independently.
