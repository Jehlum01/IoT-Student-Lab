# Troubleshooting Guide

## A systematic debugging method

1. Stop and observe the symptom.
2. Check power.
3. Check GND.
4. Check physical wiring.
5. Check pin definitions.
6. Check board selection.
7. Check libraries.
8. Use Serial Monitor where available.
9. Test components individually.
10. Change one thing at a time.

## Golden Rule

> **Do not change five things at once. You will not know which change fixed the problem.**
