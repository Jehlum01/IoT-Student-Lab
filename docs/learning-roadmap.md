# Learning Roadmap

## The progression

**Output → Input → Sense → Decide → Act → Display → Connect → Automate → Create**

| Stage | Student Capability |
|---|---|
| Level 1 | Control simple outputs and write basic programs |
| Level 2 | Read inputs and sensors and make decisions |
| Level 3 | Control actuators and display information |
| Level 4 | Connect devices using Wi-Fi and IoT concepts |
| Level 5 | Explore advanced connected systems |
| Capstone | Design and integrate complete solutions |

The student should become progressively more independent at each stage.
