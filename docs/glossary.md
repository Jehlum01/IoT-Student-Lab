# IoT Student Lab Glossary

| Term | Meaning |
|---|---|
| GPIO | General Purpose Input/Output |
| HIGH | Digital logic high |
| LOW | Digital logic low |
| Sensor | Device that provides information about the environment |
| Actuator | Device controlled by the system to produce an action |
| ADC | Analog-to-Digital Converter |
| LDR | Light-dependent resistor |
| PIR | Passive infrared motion sensor |
| PWM | Pulse Width Modulation |
| Wi-Fi | Wireless network connectivity |
| IoT | Internet of Things |
| HTTP | Protocol commonly used for web communication |
| MQTT | Lightweight messaging protocol commonly used in IoT |
