## 4. Main Control Logic

```mermaid
flowchart TD
    START([Start])
    INIT["Initialize Arduino<br/>Initialize HC-SR04<br/>Attach Servo"]
    CLOSED["Door CLOSED"]
    MEASURE["Measure Distance"]
    DETECT{"Object detected?<br/>Distance below threshold"}
    OPEN["Open Door"]
    RESET["Reset / Start Timer"]
    PRESENT{"Object still present?"}
    WAIT["Wait / Keep Door Open"]
    AWAY["Object has moved away"]
    TIMER{"Has 3 seconds passed?"}
    CLOSE["Close Door"]
    CONTINUE["Continue Monitoring"]

    START --> INIT
    INIT --> CLOSED
    CLOSED --> MEASURE
    MEASURE --> DETECT

    DETECT -->|"NO"| CONTINUE
    CONTINUE --> MEASURE

    DETECT -->|"YES"| OPEN
    OPEN --> RESET
    RESET --> PRESENT

    PRESENT -->|"YES"| WAIT
    WAIT --> MEASURE

    PRESENT -->|"NO"| AWAY
    AWAY --> TIMER

    TIMER -->|"NO"| MEASURE
    TIMER -->|"YES"| CLOSE
    CLOSE --> CLOSED
```

## 8. Automatic Door Sequence

```mermaid
sequenceDiagram
    participant P as Person
    participant S as HC-SR04
    participant A as Arduino Uno
    participant M as SG90 Servo
    participant D as Door

    P->>S: Approaches doorway
    S->>A: Distance measurement
    A->>A: Compare distance with threshold
    A->>M: Open command
    M->>D: Move door to OPEN position
    D-->>P: Door is open

    loop While object is present
        S->>A: Measure distance
        A->>A: Keep door open
    end

    P->>S: Moves away
    S->>A: Object no longer detected
    A->>A: Start 3-second closing timer

    alt Object returns
        S->>A: Object detected again
        A->>M: Keep / reopen door
        M->>D: Door remains open
    else 3 seconds elapsed
        A->>M: Close command
        M->>D: Move door to CLOSED position
    end
```

Use this arrangement if the servo requires a separate suitable 5V supply.

```mermaid
flowchart LR

    SUPPLY["External 5V Supply"]
    SERVO["SG90 Servo"]

    ARDUINO_D10["D10"]
    ARDUINO_GND["Arduino GND"]

    SUPPLY_5V["External +5V"]
    SUPPLY_GND["External GND"]

    SERVO_VCC["Servo VCC"]
    SERVO_GND["Servo GND"]
    SERVO_SIG["Servo Signal"]

    ARDUINO_D10 --> SERVO_SIG
    SUPPLY_5V --> SERVO_VCC
    SUPPLY_GND --> SERVO_GND
    ARDUINO_GND --> SUPPLY_GND
```

> **Important:** The external supply must be suitable for the servo. Connect the external supply ground to Arduino GND so the servo signal has a common electrical reference.
