# Level 3 — Actuators, Displays & Real-World Control

Combine sensors, decisions, actuators, displays and user interaction into richer embedded systems.

## Learning Philosophy

Students progress from simple experiments to systems that combine multiple concepts.

## Expected Progress

By completing this level, students should be able to build the listed projects, explain their operation, test them systematically and troubleshoot common faults.

## Continue

Complete the projects in sequence unless the instructor recommends a different path.
