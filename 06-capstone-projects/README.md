## Capstone Expectations

Students should demonstrate:

- Problem understanding
- Hardware selection
- Circuit design
- Program logic
- Sensor/actuator integration
- Testing
- Troubleshooting
- Documentation
- Independent improvements

A capstone is successful when the student can **explain the system, not merely demonstrate it**.
