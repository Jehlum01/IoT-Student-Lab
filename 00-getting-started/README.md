# Getting Started

Welcome to the IoT Student Lab.

Before starting the projects, students should become comfortable with:

1. Basic electrical safety
2. Breadboards and jumper wires
3. LEDs and resistors
4. Digital HIGH / LOW
5. Microcontroller boards
6. Arduino IDE
7. Serial Monitor
8. Basic GitHub workflow
9. ESP32 / ESP8266 setup when required

## Recommended Order

**Electronics Basics → Arduino IDE → First Arduino Project → ESP Setup → GitHub**
