# Contributing

Thank you for helping improve IoT Student Lab.

## Contributions can include

- New educational projects
- Better explanations
- Circuit diagrams
- Troubleshooting notes
- Code improvements
- Student challenges
- Documentation fixes

## Educational standard

Contributions should prioritize clarity, reproducibility, hardware safety and student understanding.

Before submitting a change, test the project on the documented hardware where possible and update the wiring/documentation if anything changes.
