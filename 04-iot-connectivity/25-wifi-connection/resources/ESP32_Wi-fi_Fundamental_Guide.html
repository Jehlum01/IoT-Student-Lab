ESP32 + Arduino IDE Board Configuration

Step-by-Step Installation Flow

  1. 1
    Download Arduino IDE 2.x from the official website and launch it.
  2. 2
    Open File → Preferences (or Cmd + , on macOS).
  3. 3
    Locate Additional boards manager URLs field and paste the official Espressif JSON repository link below.
  4. 4
    Go to Tools → Board → Boards Manager..., search for esp32 and click Install (Espressif Systems).
  5. 5
    Select your board (e.g., ESP32 Dev Module or NodeMCU-32S) and pick the active COM / ttyUSB port.

USB Drivers Check

If your COM port doesn't show up in Arduino IDE, your operating system needs the USB-to-UART bridge chip driver:

  • CP2102: Silicon Labs driver
  • CH340 / CH341: WCH driver
Baud rate standard for Wi-Fi sketches is 115200 baud.

Wi-Fi Architecture & Fundamentals

WIFI_STA Most Common

Station Mode (STA)

The ESP32 acts as a wireless client (like a smartphone or laptop) and associates with an existing Wi-Fi router.

[Wi-Fi Router] ←RF→ [ESP32 Client]
Use case: Publishing sensor data to cloud servers or home assistant over LAN.
WIFI_AP Routerless

Access Point (AP)

The ESP32 broadcasts its own Wi-Fi beacon (SSID). Nearby smartphones connect directly to the ESP32 with zero external router.

[ESP32 Hotspot] ←RF→ [Phone/Laptop]
Use case: Initial device provisioning, field configurations, remote RC cars.
WIFI_AP_STA Dual Mode

Dual Mode (AP + STA)

Simultaneously maintains an uplink connection to the local LAN while broadcasting a setup SSID for new peers.

[Router] ↔ [ESP32 Node] ↔ [Phone]
Use case: Wi-Fi network range extenders, Wi-Fi mesh repeaters, captive portal fallback.

Core Networking Vocabulary

SSID Service Set Identifier. The human-readable name of the wireless broadcast (e.g. "Lab_WiFi").
MAC Address Unique 48-bit hardware identifier burned into ESP32 eFuse (e.g. 24:6F:28:B2:7A:1C).
IP Address Logical LAN address assigned dynamically by the router's DHCP server (e.g. 192.168.1.42).
2.4 GHz vs 5.0 GHz Critical: ESP32 WROOM only supports 2.4 GHz radios. 5 GHz Wi-Fi will never be seen.

RSSI Signal Strength Breakdown

RSSI (Received Signal Strength Indicator) is measured in negative decibel milliwatts (dBm). Closer to 0 means stronger signal.

-30 to -60 dBm Excellent (High throughput, reliable)
-60 to -75 dBm Good / Acceptable for IoT
-75 to -85 dBm Weak (Frequent packet dropouts)
< -88 dBm Unusable (Disconnections)
Query in code: WiFi.RSSI() Unit: dBm
