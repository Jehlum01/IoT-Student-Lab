# Level 4 — IoT & Connectivity

Introduce ESP-based connectivity and turn standalone embedded projects into network-connected systems.

## Learning Philosophy

Students progress from simple experiments to systems that combine multiple concepts.

## Projects

| # | Project | Main Concept |
|---:|---|---|
| 25 | [Wi-Fi Connection](25-wifi-connection/README.md) | ESP networking |
| 26 | [Web Server](26-web-server/README.md) | HTTP & web interface |
| 27 | [IoT LED Control](27-iot-led-control/README.md) | Remote control |
| 28 | [IoT Temperature Monitor](28-iot-temperature-monitor/README.md) | Sensor + cloud |
| 29 | [IoT Motion Alarm](29-iot-motion-alarm/README.md) | Connected security |
| 30 | [Smart Home Automation](30-smart-home-automation/README.md) | IoT + automation |

## Expected Progress

By completing this level, students should be able to build the listed projects, explain their operation, test them systematically and troubleshoot common faults.

## Continue

Complete the projects in sequence unless the instructor recommends a different path.
