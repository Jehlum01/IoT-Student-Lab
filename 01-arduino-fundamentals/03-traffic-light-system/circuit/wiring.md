# 🔌 Project 03 — Circuit & Wiring

## 🚦 Traffic Light System

This project uses three LEDs to simulate a simple traffic signal.

Unlike Projects 01 and 02, the microcontroller now controls **three independent digital outputs**.

> 💡 Same basic LED principle. Three coordinated outputs.

---

## 🔧 Wiring

```text
Arduino D8  → 220 Ω → RED LED    → GND
Arduino D9  → 220 Ω → YELLOW LED → GND
Arduino D10 → 220 Ω → GREEN LED  → GND
