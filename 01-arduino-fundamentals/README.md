# Level 1 — Arduino Fundamentals

Build a strong foundation in microcontrollers, digital electronics and basic Arduino programming.

## Learning Philosophy

Students progress from simple experiments to systems that combine multiple concepts.

## Projects

| # | Project | Main Concept |
|---:|---|---|
| 01 | [Blinking LED](01-blinking-led/README.md) | Digital output |
| 02 | [Random LED Glow & Variable Timing](02-random-led/README.md) | Variables & randomness |
| 03 | [Traffic Light System](03-traffic-light/README.md) | Multiple outputs & sequencing |
| 04 | [Pedestrian Traffic Light](04-pedestrian-traffic-light/README.md) | Digital input & conditions |
| 05 | [LED Chase / Running LEDs](05-led-chase/README.md) | Loops & multiple GPIOs |
| 06 | [LED Pattern Generator](06-led-pattern-generator/README.md) | Arrays & binary patterns |

## Expected Progress

By completing this level, students should be able to build the listed projects, explain their operation, test them systematically and troubleshoot common faults.

## Continue

Complete the projects in sequence unless the instructor recommends a different path.
