# Level 2 — Challenge & Practice

## Sensors, Inputs & Automation

Level 2 moves from simple output programming to interactive embedded systems.

The core engineering pattern is:

**Sense → Decide → Act**

Students have worked with:

- Digital inputs
- Push buttons
- State variables
- Toggle logic
- LDR sensors
- Analog inputs
- Thresholds
- Temperature sensors
- Actuators
- PIR motion sensors
- Buzzers
- Timing
- `millis()`
- Basic automation

This module tests whether those concepts can be applied independently.

# Engineering Rule

Do not immediately replace code when something fails.

Use:

**Observe → Hypothesize → Test → Fix → Verify**

The goal is not simply to make the circuit work.

The goal is to understand why it works.
