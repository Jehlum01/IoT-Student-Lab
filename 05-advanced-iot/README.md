# Level 5 — Advanced IoT

## Purpose

This level extends the core IoT journey into more advanced connected-system concepts.

## Suggested Topics

- MQTT
- Cloud platforms
- APIs
- Data visualization
- Remote monitoring
- Automation rules
- Multi-device systems
- IoT security
- Edge processing
- Advanced ESP32 applications

## Learning Approach

Advanced topics should be introduced after students are comfortable with:

**microcontrollers → sensors → actuators → displays → Wi-Fi → basic IoT**

## Student Challenge

Design an IoT system that combines at least three previously learned concepts and document:

1. Problem statement
2. System architecture
3. Hardware
4. Software
5. Connectivity
6. Testing
7. Failure cases
8. Future improvements
